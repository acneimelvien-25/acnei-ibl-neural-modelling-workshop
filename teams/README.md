# Team workspace overview

This folder is the central collaboration space for the five workshop teams.

## Teams

- Team 01: `team-01/`
- Team 02: `team-02/`
- Team 03: `team-03/`
- Team 04: `team-04/`
- Team 05: `team-05/`

## Team rules

- Each team has its own folder.
- Every team should keep a `README.md` explaining its project.
- Use the same general folder layout across teams.
- Store final outputs in `results/` or `reports/`.
- Use GitHub pull requests to share work.

## Suggested structure per team

```text
teams/team-XX/
├── README.md
├── data/
├── notebooks/
├── scripts/
├── results/
├── reports/
└── notes/
```

## Shared workshop objective

The goal is to let each team work on a different modelling or analysis project while still sharing a common repository for collaboration, version control, and uploading results.

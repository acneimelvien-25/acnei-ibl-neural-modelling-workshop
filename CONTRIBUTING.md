# Contributing

Thank you for contributing to the ACNEI-IBL Neural Modelling Workshop repository.

## Contribution workflow

1. Clone the repository.
2. Create a new branch for your work.
3. Add or edit files in your team folder.
4. Commit with a clear, descriptive message.
5. Push your branch.
6. Open a pull request for review.

## Team folder rules

- Work only inside your assigned team directory.
- Keep files organised by type: `data`, `notebooks`, `scripts`, `results`, `reports`.
- Do not change other teams' work without permission.
- Add a README in each team folder so others can understand the project.

## Naming conventions

Use clear names such as:

- `team-01`
- `team-02`
- `team-03`
- `team-04`
- `team-05`

Use descriptive filenames such as:

- `data_preprocessing.py`
- `model_training.ipynb`
- `results_summary.md`

## Good pull request practices

- Explain what the team changed
- Summarise the main findings
- Include links to notebooks or reports when relevant
- Ask for review from the workshop organisers or another team

## Collaboration expectations

This repository is meant to support cross-team collaboration. Make your work easy to read, easy to reproduce, and easy to share.
